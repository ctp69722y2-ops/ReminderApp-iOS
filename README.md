## 🎯 أمثلة الاستخدام

### إضافة تذكير جديد
1. اضغط على زر **+** الأزرق في أسفل اليمين
2. أدخل **عنوان التذكير** والوصف
3. اختر **التاريخ والوقت**
4. اختر **التصنيف**
5. فعّل **الإشعارات** إذا أردت
6. اضغط **حفظ**

### تعديل تذكير
1. اذهب إلى التبويب المناسب (القادمة، المتأخرة، المكتملة)
2. اضغط على التذكير المطلوب
3. عدّل المعلومات
4. اضغط **حفظ**

### حذف تذكير
1. في قائمة التذكيرات، اسحب التذكير لليسار
2. اضغط على **حذف**

### تحديد تذكير كمكتمل
1. اسحب التذكير لليمين
2. اضغط على **إكمال**

## 🛠️ هيكل الكود

### Reminder Model
```swift
struct Reminder: Identifiable, Codable {
    var id: UUID
    var title: String
    var description: String
    var date: Date
    var time: Date
    var isCompleted: Bool
    var category: ReminderCategory
    var notificationEnabled: Bool
}
```

### ReminderManager (ViewModel)
```swift
class ReminderManager: ObservableObject {
    @Published var reminders: [Reminder]
    
    func addReminder(_ reminder: Reminder)
    func updateReminder(_ reminder: Reminder)
    func deleteReminder(_ reminder: Reminder)
    func markAsCompleted(_ reminder: Reminder)
}
```

### Services
- **NotificationService**: إدارة الإشعارات والتذكيرات
- **StorageService**: حفظ وتحميل البيانات
